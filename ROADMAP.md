# Secure communication roadmap

All releases remain `0.x` until their standards, interoperability evidence, and
independent review justify otherwise.

1. Key transparency contracts, providers, PaaS log/monitor/auditor services, and
   recurring split-view drills.
2. MLS cross-implementation certification and independent-audit readiness.
3. `secure-messaging` plus interchangeable messaging providers for conversation
   semantics, delivery, ordering, expiry, attachments, recovery, and abuse controls.
4. MIMI-compatible identity, introduction, federation, and application framing as
   the IETF drafts mature.
5. `secure-transfer` plus providers for chunked, resumable, authenticated file and
   stream delivery, with explicit inspection and recovery modes.
6. Provider-neutral agent identity, delegation chains, rotation, revocation,
   workload identity, and independently verifiable action receipts.
7. Expanded Agent Exchange sources, destinations, multi-party approval, human
   escalation, and high-risk transaction policies.
8. Post-quantum algorithm agility now, followed by standards-gated hybrid HPKE and
   MLS providers once the IETF suites and implementations stabilize.
9. Examples, conformance targets, version-bound certification, PaaS admission, and
   repeatable security drills for every release family.
